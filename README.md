# Executive AI Chief of Staff

An AI-powered executive operating system built with Python and Streamlit.

## Features
- AI task extraction from voice and text
- Google Calendar sync
- Gmail AI assistant with smart drafts
- WhatsApp bot integration
- Daily executive briefing
- Project intelligence dashboard

## Tech Stack
- Python / Streamlit
- OpenAI GPT-4
- Google Calendar & Gmail API
- SQLite
- Twilio WhatsApp
